# Source notices

The four CSV files in `../sources/` are unmodified AffilGood v1.0.0 files from commit `9be394d5a8b11360b877ce59fb2355b0a7fa867e`. The owning Apache 2.0 notice is retained in `AffilGood-APACHE-2.0.txt`. Cite Duran-Silva, Accuosto, Przybyła and Saggion, [AffilGood: Building reliable institution name disambiguation tools to improve scientific literature analysis](https://aclanthology.org/2024.sdp-1.13/), SDP 2024.

The registry is [ROR v1.41, 13 February 2024](https://github.com/ror-community/ror-data/blob/main/v1.41-2024-02-13-ror-data.zip). [ROR IDs and metadata are distributed under CC0 1.0](https://ror.org/about/terms/). The prepared registry preserves all statuses. Organization names, aliases, multilingual labels and address cities are selected from this release; identifiers are replaced by opaque IDs in inference files. The original mapping remains separate for evaluation.

The ROR source also identifies address enrichment as data from [GeoNames](https://www.geonames.org/), under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). This attribution is retained for the derived city fields.

The historic S2AFF source is read only to audit overlap. Its text is not copied into this package. The manifest records the source hash. Existing S2AFF licences remain with the earlier experiment's data.
